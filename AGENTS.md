# KineJing maintenance

- Preserve sources, licenses and `backends.json` pinned versions.
- The baseline is nonparametric. External launchers are not evidence of neural-model reproduction.
- No leaderboard score, new trained weights, partnership or causal claim without an artifact.
- Keep negative experiments and distinguish local image metrics from TWB-Score.
- Do not commit credentials, local absolute paths, contact emails, datasets or checkpoints.
- Run `python -m unittest discover -s tests -v`, the CPU demo and `python scripts/verify_evidence.py` for relevant changes.
- Never silently ignore unsupported action inputs or load random weights as a fallback.
- Prose metrics must be generated from JSON, not transcribed.
